# 🎵 Type Rhythm Game

**Type Rhythm Game** is a browser-based mini-game designed to improve typing speed and reflexes through rhythm-based mechanics. Words fall from the top of the screen, and players must type them correctly before they reach the bottom. As difficulty increases, so does the pace—making it both challenging and engaging.

---

## 🚀 Features

- 🕹️ Interactive gameplay with real-time feedback
- ⏱️ Multiple difficulty levels with increasing speed
- 💥 Dynamic word animations and clean visuals
- 📈 Scoring system that rewards accuracy and speed

---

## 📚 Literature Review

Typing games are a proven way to improve typing skills, but most focus only on speed. This project addresses the gap by combining rhythm-based challenge with visual feedback.

- **Why:** Most typing games lack engaging rhythm elements.
- **How:** Introduces falling speed mechanics and visual transitions.
- **Topics Covered:** Gamified learning, cognitive training, typing tutors.
- **Gap:** Lack of casual typing games that merge rhythm, speed, and design.

---

## ⚙️ Methodology

### Technologies Used

- **HTML** – Builds the layout (scoreboard, input box, difficulty selection).
- **CSS** – Animates falling words and ensures responsive design.
- **JavaScript** – Manages word logic, scoring, input validation, and game flow.

### Game Flow

1. Player selects a difficulty.
2. Words start falling at intervals.
3. Typing correct words removes them and scores points.
4. Missed words deduct points.
5. Game ends if the score drops below zero.
